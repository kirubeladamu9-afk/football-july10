┌─ DATABASE TABLES ──────────────────────────────────────────────────────────┐
│                                                                             │
│  admin_users                                                                │
│    • id (INT, PRIMARY KEY)                                                 │
│    • email (VARCHAR, UNIQUE)                                               │

│    • name (VARCHAR)                                                        │
│    • role (VARCHAR, default 'admin')                                       │
│    • created_at, updated_at (TIMESTAMPS)                                   │
│                                                                             │
│  blogs                                                                      │
│    • id (INT, PRIMARY KEY)                                                 │
│    • slug (VARCHAR, UNIQUE) - auto-generated from title                    │
│    • title_en, title_am (VARCHAR) - bilingual                              │
│    • excerpt_en, excerpt_am (TEXT)                                         │
│    • body_en, body_am (LONGTEXT) - HTML from rich editor                   │
│    • featured_image_url (VARCHAR)                                          │
│    • category (VARCHAR) - politics, law, society                           │
│    • tags (JSON)                                                           │
│    • status (ENUM: draft, published, scheduled)                            │
│    • publish_date (DATETIME)                                               │
│    • author_id (INT, FOREIGN KEY)                                          │
│    • created_at, updated_at (TIMESTAMPS)                                   │
│                                                                             │
│  multimedia                                                                 │
│    • id (INT, PRIMARY KEY)                                                 │
│    • type (ENUM: audio, video)                                             │
│    • title_en, title_am (VARCHAR) - bilingual                              │
│    • description_en, description_am (TEXT)                                 │
│    • file_url (VARCHAR)                                                    │
│    • thumbnail_url (VARCHAR)                                               │
│    • duration_seconds (INT)                                                │
│    • status (ENUM: draft, published, scheduled)                            │
│    • publish_date (DATETIME)                                               │
│    • created_at, updated_at (TIMESTAMPS)                                   │

┌─ TROUBLESHOOTING ──────────────────────────────────────────────────────────┐

│    → Check MySQL is running                                                │
│    → Verify connection variables in .env.local                             │
│    → Test with: mysql -h $MYSQLHOST -u $MYSQLUSER -p                      │
│                                                                             │
│  Issue: Login fails                                                        │
│    → Run: node lib/seed-db.js                                              │
│    → Check admin_users table exists                                        │
│    → Verify password hash is correct                                       │
│                                                                             │
│  Issue: Images not showing                                                 │
│    → Provide absolute URLs (not relative paths)                            │
│    → Use CDN or cloud storage                                              │
│    → Check CORS if using external service                                  │
│                                                                             │
│  Issue: Styling missing                                                    │
│    → Clear browser cache and hard refresh                                  │
│    → Check src/styles/admin.scss is being imported                         │
│    → Verify SCSS compilation is working                                    │
